# 🎮 Simon Says Game

A modern and responsive **Simon Says memory game** built using **HTML,
CSS, and Vanilla JavaScript**.

Test your memory skills by repeating the color sequence correctly.\
Each level adds a new step --- how far can you go? 🚀

## ✨ Features

-   🎯 Progressive difficulty (new color each level)
-   ✨ Smooth flash animations
-   🔊 Sound effects (click + game over)
-   📊 Current score tracking
-   🏆 Highest score tracking
-   📱 Fully responsive design
-   🎨 Modern gradient UI

------------------------------------------------------------------------

## 🛠 Tech Stack

-   **HTML5** -- Structure\
-   **CSS3** -- Styling & Animations\
-   **JavaScript (ES6)** -- Game Logic

------------------------------------------------------------------------

## 🎮 How to Play

1.  Click **Start Game**
2.  Watch the flashing color carefully 👀
3.  Repeat the sequence in the same order
4.  Each level adds one more color
5.  One wrong move ends the game ❌
